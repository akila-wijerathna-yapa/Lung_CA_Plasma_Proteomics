# Large-Scale Plasma Proteomic Profiling Reveals Treatment-Stratified Landscapes and Prognostic Biomarkers in Lung Cancer

## Overview

This repository contains the R scripts used for the analyses associated with the following conference abstract:

Kulasinghe, A., Wijerathna-Yapa, A., Kilgallon, A., Parina, P., Shaw, T., Toms, B., Mullally, W., & O’Byrne, K. (2026). P2.088: Large-Scale Plasma Proteomic Profiling Reveals Treatment-Stratified Landscapes and Prognostic Biomarkers in Lung Cancer. *Journal of Thoracic Oncology, 21*(10, Suppl. 1), 104870.

## Repository contents

The R scripts in this repository support the computational analyses associated with the abstract. See the individual scripts and their comments for details on their purpose, required inputs, and execution order.

## Data availability

The datasets used in this study are not included in this repository. Researchers seeking access to the data should contact the corresponding author of the manuscript.

## Reproducibility

Before running the scripts, review each script for required input files, package dependencies, and configuration settings. Results may depend on the data version, software environment, and analysis parameters used.
